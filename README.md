# IAB Smart Baggage Eco System

Build a professional enterprise-grade airport baggage management web application called "Smart Baggage Ecosystem".

The application should look like a modern airport operations system used by airlines and ground handling companies.

Use a clean corporate aviation style with dark blue, white and light grey colors.

The application should be responsive for desktop, tablet and mobile devices.

Create the following modules:

1. Executive Dashboard

Display KPI cards:

- Total Bags

- Open Cases

- Located Bags

- Ready for Delivery

- Delivered Bags

- Average Resolution Time

Add charts showing baggage status distribution.

-------------------------------------------------

2. Lost & Found Management

Create a form to register a new baggage case:

- Passenger Name

- Flight Number

- PIR Number

- Bag Tag Number

- Arrival Date

- Contact Number

- Email

- Baggage Description

Generate a unique Bag ID automatically.

Display all baggage records in a searchable table.

-------------------------------------------------

3. Storage Control

Create storage location management.

Each bag should be assigned to:

- Zone

- Shelf

- Position

Display storage information in a clean table.

-------------------------------------------------

4. Passenger Tracking Portal

Create a public tracking page.

Passenger enters PIR Number.

System displays:

- Case Status

- Current Location

- Assigned Storage Area

- Delivery Status

Statuses:

Missing

Located

Stored

Ready For Delivery

Out For Delivery

Delivered

-------------------------------------------------

5. Home Baggage Delivery

Create delivery management screen.

Fields:

- Delivery ID

- Passenger Name

- Address

- Delivery Status

- Assigned Driver

Statuses:

Pending

Assigned

Out For Delivery

Delivered

-------------------------------------------------

6. Sample Demo Data

Populate the application with realistic sample baggage cases.

Use Cairo International Airport as sample data.

Use realistic passenger names and baggage information.

-------------------------------------------------

7. Navigation

Professional sidebar navigation.

Dashboard

Lost & Found

Storage Control

Passenger Tracking

Delivery Management

Reports

-------------------------------------------------

The application should feel like a real operational airport baggage management platform ready for executive demonstration.
